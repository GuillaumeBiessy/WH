1 · Documentation fonctionnelle

Vue d'ensemble

WH applique le lissage de Whittaker-Henderson pour graduer des tables actuarielles à une dimension (taux par âge) ou deux dimensions (taux par âge × ancienneté), typiquement pour quantifier des risques d'assurance vie : mortalité, incapacité, dépendance (LTC), rachat, défaut, chômage.

Par rapport au lissage WH « historique », le package apporte :

  • une estimation par maximum de vraisemblance (cadre analyse de survie, Poisson) — fortement recommandée — en plus du cadre de régression gaussien approché ;
  • la sélection automatique du/des paramètre(s) de lissage \(\lambda\) (REML par défaut, sinon AIC/BIC/GCV) ;
  • l'extrapolation au-delà de la plage observée ;
  • une implémentation efficace (stockage bande compact + LAPACK) en C++.

Le package expose une seule fonction principale, WH(), qui renvoie un objet WH_1d ou WH_2d ; des méthodes S3 (print, plot, predict, vcov) et un utilitaire output_to_df() s'appliquent ensuite. Deux jeux de données fictifs accompagnent le package : portfolio_mort (mortalité 1D, rente) et portfolio_LTC (mortalité d'incapables 2D, dépendance).

2 · Documentation mathématique

Notation : \(n\) points (1D) ou \(n=n_x n_z\) (2D), \(W=\mathrm{Diag}(\mathbf w)\) poids, \(D_{n,q}\) matrice de différence d'ordre \(q\) (dimensions \((n-q)\times n\)), \(\theta\) le log-taux à estimer.

Le critère de Whittaker-Henderson

1D. L'estimateur minimise fidélité + lissage :

$$\hat{\mathbf y}=\underset{\theta}{\arg\min}\Big\{(\mathbf y-\theta)^TW(\mathbf y-\theta)+\theta^TP_\lambda\theta\Big\},\qquad P_\lambda=\lambda\,D_{n,q}^TD_{n,q}.$$

avec \((\Delta^q\theta)_i=\sum_{k=0}^q \binom{q}{k}(-1)^{q-k}\theta_{i+k}\), \(D_{n,q}=D_{n-1,q-1}D_{n,1}\). 2D (Kronecker) :

$$P_\lambda=\lambda_x\,I_{n_z}\otimes D_{n_x,q_x}^TD_{n_x,q_x}+\lambda_z\,D_{n_z,q_z}^TD_{n_z,q_z}\otimes I_{n_x}.$$

Solution explicite (si \(W+P_\lambda\) inversible) : \(\hat{\mathbf y}=(W+P_\lambda)^{-1}W\mathbf y\). Matrice chapeau \(H=(W+P_\lambda)^{-1}W\), degrés de liberté effectifs \(\mathrm{edf}=\mathrm{tr}(H)\).

Dans le code : create_P_compact_cpp(n,q) construit \(D^TD\) en stockage bande ; combine_lambda_P applique \(\lambda\) et assemble le cas 2D ; fit_pen_reg ajoute \(W\) à la diagonale, factorise \(R=\mathrm{chol}(W+P_\lambda)\) et résout par deux back-solves (coût \(O(p^2)\), pas d'inversion explicite).

Cadre analyse de survie / maximum de vraisemblance

On pose l'offset \(o_i=\log e^c_i\) et le modèle de Poisson \(d_i\sim\mathrm{Poisson}(\mu_i)\), \(\mu_i=\exp(\theta_i+o_i)\). On maximise la log-vraisemblance pénalisée \(\ell(\theta)-\tfrac12\theta^TP_\lambda\theta\) par PIRLS :

  • poids de travail \(W_k=\mathrm{Diag}(\mu)=\mathrm{Diag}(e^{\theta+o})\) (code new_wt) ;
  • réponse de travail \(z=\theta+(d-\mu)/\mu=\theta+d/\mu-1\) (code compute_z) ;
  • mise à jour : résoudre \((W_k+P_\lambda)\theta=W_k z\) (code : tXWz = wt*z puis fit_pen_reg) ;
  • step-halving sur la déviance pénalisée tant qu'elle ne décroît pas (code get_valid_beta).

Résidus de déviance de Poisson \(r_i=\mathrm{sign}(d_i-\mu_i)\sqrt{2\max(d_i\log(d_i/\mu_i)-(d_i-\mu_i),0)}\), déviance \(\mathrm{dev}=\sum r_i^2\) (code compute_res_deviance). La matrice modèle est l'identité (\(X=I\)) : chaque point a son propre paramètre, ce qui rend chaque pas PIRLS très léger.

Cadre de régression (approximation normale, WH historique)

On prend \(y_i=\log(d_i/e^c_i)\) (log-taux brut) et \(w_i=d_i\) ; modèle \(\mathbf y\mid\theta\sim\mathcal N(\theta,\sigma^2W^{-})\). La solution est en forme close, sans PIRLS : \(\hat\theta=(W+P_\lambda)^{-1}W\mathbf y\). Résidus \(r=\sqrt{w}\,(y-\hat\theta)\), \(\mathrm{dev}=\sum r_i^2\) (RSS pondérée).

Lecture bayésienne : variance, intervalles, edf

Le terme de pénalité équivaut à un a priori gaussien \(\theta\mid\lambda\sim\mathcal N(0,\sigma^2P_\lambda^{-})\). La covariance a posteriori des valeurs ajustées est \(V=(W+P_\lambda)^{-1}\) (à \(\sigma^2\) près), d'où :

  • écart-type \(\texttt{std\_y\_hat}_i=\sqrt{V_{ii}}\) (diag_V_compact_cpp(R)) ;
  • vcov() renvoie \(V=R^{-1}R^{-T}\) (invert_cholesky_compact_lapack + tcrossprod) ;
  • degrés de liberté par point \(\mathrm{edf}_i=w_i V_{ii}=H_{ii}\), total \(\sum_i\mathrm{edf}_i=\mathrm{tr}(H)\) (edf = wt * diag_V).

Sélection du paramètre de lissage

Quatre critères, tous calculés dans get_diagnosis / WH_outer_aux (\(n_*\) = nb de poids strictement positifs, n_pos) :

CritèreFormule (code)À
AIC\(\mathrm{dev}+2\,\mathrm{edf}\)min
BIC\(\mathrm{dev}+\log(n_*)\,\mathrm{edf}\)min
GCV\(n_*\,\mathrm{dev}/(n_*-\mathrm{edf})^2\)min
REML / LAML\((\mathrm{dev}+\mathrm{pen})/2+K/2-\ell_{\mathrm{sat}}\)min

avec la constante compute_K :

$$K=\underbrace{2\textstyle\sum_i\log R_{ii}}_{\log|W+P_\lambda|}-\underbrace{\log|P_\lambda|_+}_{\text{pseudo-dét.}}-\;q\log(2\pi),$$ $$\log|P_\lambda|_+=\begin{cases}(p-q)\log\lambda+\sum_{i>q}\log s_i & \text{(1D)}\\[2pt]\sum_{s>0}\log(\lambda_x s_x+\lambda_z s_z) & \text{(2D)}\end{cases}$$

où \(s\) = valeurs propres de \(D^TD\) (eigenvalues_compact_lapack, les \(q\) premières forcées à 0). Terme saturé \(\ell_{\mathrm{sat}}=-n_*/2\,\log(2\pi)\) en régression, \(0\) en ML (absorbé dans la déviance). Minimiser ce score équivaut à maximiser la LAML du papier \(\ell^m_{\mathrm{LAML}}=\ell(\hat\theta)-\tfrac12[\hat\theta^TP_\lambda\hat\theta+\log|W_\lambda+P_\lambda|-\log|P_\lambda|_+-q\log 2\pi]\). MATCH

Le papier note que REML/vraisemblance marginale est plus robuste en échantillon fini que GCV/AIC (qui peuvent sur-ajuster : GCV a parfois deux minima locaux). D'où le défaut "REML".

Algorithmes d'optimisation de \(\lambda\)

Le package optimise toujours sur \(\log\lambda\). Ce qui est livré (WH_outer) : une itération externe (outer) avec un optimiseur sans dérivée :

  • 1D : stats::optimize (Brent) sur \(\log\lambda\in[-6,12]\log 10\) ;
  • 2D : stats::optim (Nelder-Mead) ; \(\lambda\) initial via find_starting_lambda (uniroot calant \(\overline{w/(w+\lambda\,\mathrm{diag}P)}=0.2\), une edf/point cible ≈ 0,2). Le papier (Algorithme 2) ne fixe qu'« une valeur initiale arbitraire » : ce ratio 0,2 est un choix d'implémentation non décrit — voir §5-C.
  • boucle interne : PIRLS avec démarrage à chaud (eta_start réutilisé d'une itération externe à l'autre) ;
  • auto_transpose : en 2D, transpose si \((q_x+1)/n_x<(q_z+1)/n_z\) pour minimiser la largeur de bande effective \(q_z\,n_x\). C'est exactement la règle de permutation du papier (§sec-reduction) ; la condition du code y est algébriquement identique.

Le papier développe en outre — non implémentés dans le package — la méthode Fellner-Schall généralisée (mise à jour multiplicative, sans dérivée), l'algorithme de Newton (dérivées 1re/2de de la LAML), et deux schémas de nesting alternatifs (performance iteration, alternate iteration). Voir §5.

Pourquoi le choix sans-dérivée tient la route
Le papier (§ Performance comparison) mesure, en outer iteration, une erreur relative sur la LAML <10⁻⁷ pour Brent/Nelder-Mead (vs <10⁻¹⁰ pour Newton). Comme la matrice modèle est l'identité, les pas PIRLS sont très bon marché : le surcoût en itérations du sans-dérivée est peu pénalisant en 1D (≈5 ms) et acceptable en 2D (≈1,7 s/itération Nelder-Mead). Newton reste le plus rapide+précis, donc « non optimal » mais « suffisant et simple ».

Efficacité : l'optimisation « bande »

\(P_\lambda\) est une matrice bande (largeur \(q\) en 1D). Le package ne stocke jamais les matrices pleines : il utilise un stockage compact \((q+1)\times p\) et des kernels LAPACK bande :

La réduction de rang / paramétrisation naturelle / GLAM (§sec-vp, §sec-rr) — autre voie d'accélération du papier — n'est pas dans le code livré (les valeurs propres ne servent qu'au log-déterminant, pas à réduire la base). Voir §5.

Extrapolation

Principe commun (§sec-extra du papier) : on plonge la grille observée dans une grille élargie via une matrice de sélection \(C\) (\(C\mathbf y_+\) extrait les positions observées, \(CC^T=I\)), on pose un poids nul sur les nouveaux points (\(W_+=C^TWC\)), et on minimise le critère étendu \((\mathbf y_+-\theta_+)^TW_+(\mathbf y_+-\theta_+)+\theta_+^TP_+\theta_+\) à \(\lambda\) fixé (hérité de l'ajustement).

1D — non contraint (predict.WH_1d). Solution directe \(\hat{\mathbf y}_+=(W_++P_+)^{-1}W_+\mathbf y_+\). Le code étend la grille (create_P_compact_cpp(n_tot,q)), place 0 dans wt et tXWz aux nouveaux points, re-résout par fit_pen_reg, et lit l'écart-type sur \(\sqrt{\textbf{diag}(W_++P_+)^{-1}}\) (diag_V_compact_cpp(fit$R)). Le papier démontre qu'en 1D le bloc \(D_2\) est triangulaire inversible, donc \(V_+^{11}=V\) : l'ajustement initial reste inchangé et l'extrapolation prolonge la tendance par un polynôme de degré \(q-1\) (Carballo al. 2021). MATCH

2D — contraint (predict.WH_2d). En 2D la simplification précédente tombe : une extrapolation non contrainte modifierait les valeurs ajustées (la pénalité, plus seule à peser, re-lisse tout). On impose donc \(C\hat\theta_+^\ast=\hat{\mathbf y}\) via un multiplicateur de Lagrange (Carballo al. 2021). La solution en forme close est \(\hat{\mathbf y}^\ast_+=Q^T\big[\,I\,;\,-(P_+^{22})^{-1}P_+^{21}\,\big]^T\hat{\mathbf y}\), c.-à-d. valeurs observées conservées, nouvelles valeurs \(\hat{\mathbf y}_{\text{new}}=-(P_+^{22})^{-1}P_+^{21}\hat{\mathbf y}\).

Dans le code : R_22 est la factorisée de Cholesky du bloc de pénalité sur les nouveaux points \(P_+^{22}\) (et non un complément de Schur) : submatrix_compact_cpp(P_pred, ind_fit) retire les indices observés (ind_fit) et garde les nouveaux. get_y_new_compact calcule \(P_+^{21}\hat{\mathbf y}\) puis \(-(P_+^{22})^{-1}\!\cdot\) via deux back-solves sur R_22 — exactement la formule. La variance \(V_+^\ast\) sur le bloc nouveau est \((P_+^{22})^{-1}P_+^{21}\,V\,P_+^{12}(P_+^{22})^{-1}+(P_+^{22})^{-1}\) : get_diag_V_pred_compact accumule \(\sum_j(BR^{-1}e_j)^2\) (terme de propagation, où \(B=(P_+^{22})^{-1}P_+^{21}\)) et + diag_V_compact_cpp(R_22) ajoute le terme d'innovation \((P_+^{22})^{-1}\). Détail révélateur : la boucle de variance est alimentée par object$R — la Cholesky de l'ajustement d'origine, donc le \(V\) original et non \(V_+^{11}\). Utiliser \(V\) plutôt que \(V_+^{11}\) est précisément la signature de la solution contrainte. MATCH

4 · Comparaison aux papiers de Wood

Le fil conducteur : WH est le cas particulier \(X=I\) du cadre de Wood
Les méthodes de sélection de \(\lambda\) du papier (et donc du package) sont des spécialisations, au modèle à matrice identité, du cadre GLM pénalisé / REML développé par S. Wood pour mgcv. Conséquence centrale : chez Wood la matrice modèle \(X\) (bases de splines à rang réduit) est l'objet coûteux — tout le moteur gdi/bam sert à former et factoriser \(X^TWX\). En WH, \(X=I\) : il y a un paramètre par point, \(\hat{\boldsymbol\beta}=\hat{\boldsymbol\theta}\), les pas PIRLS sont triviaux, et aucun produit \(X^TWX\) n'existe. Une bonne part de la machinerie « gros volumes » de Wood est donc sans objet ici ; le levier d'efficacité de WH est ailleurs (la bande de \(P_\lambda\)).

Pour chaque sujet : ce que fait le package (X), ce que fait Wood / mgcv (Y), l'écart (Z). Articles lus : cartographie fonctionnelle de mgcv + les 4 PDF ci-dessous.

Wood2011 — JRSS-B, « Fast stable REML and ML estimation of semiparametric GLMs »		 Calcule la LAML (compute_K/compute_REML) et l'optimise sans dérivées (Brent/Nelder-Mead). Le score REML est exactement la LAML de Wood2011 prise en \(X=I\). Même approximation de Laplace de la REML/ML, pour \(X\) général, optimisée par Newton sur \(\ln\lambda\) avec dérivées 1re/2de obtenues par différentiation implicite (\(d\hat\beta/d\lambda\), \(d\,\mathrm{tr}(A)/d\lambda\)…, moteur gdi). Exige Newton-Raphson (pas Fisher scoring) pour l'ajustement. WH ne calcule pas les dérivées de la LAML → pas de Newton. Pas un bug : la maths est la même (cas \(X=I\)), seul l'optimiseur diffère. Voir §5-A.
Fellner-Schall
Wood2017fellnerschall — Biometrics, « A Generalized Fellner-Schall Method »		 Non implémenté. Le papier WH présente la formule de mise à jour multiplicative (eq-fs) mais le code livré ne l'expose pas. Généralise Fellner(1986)/Schall(1991) aux pénalités linéaires en plusieurs \(\lambda\) (tensoriels, adaptatifs) ; prouve que chaque pas augmente la REML ; ne requiert que les dérivées 1re/2de déjà nécessaires à l'estimation de \(\beta\). Alternative sans dérivée explicite, robuste, peu coûteuse, absente de WH — fournie par le package frère WHfull. Voir §5-A.
Stratégies de nesting
performance : Gu1992 · alternate : Wood2017blacksmoke		 Livre uniquement l'outer iteration (PIRLS complet pour chaque \(\lambda\) candidat). Performance et alternate iteration décrites au papier, pas au code. Wood2017blacksmoke (JASA, « GAMs for Gigadata ») emploie l'alternate / single iteration : \(\theta\) et \(\lambda\) mis à jour en alternance, sans optimiser pleinement à chaque pas — clé pour les très grands volumes. Nesting alternatif absent de WH (présent dans WHfull). Le papier WH note qu'ils manquent de garantie de convergence formelle ; l'outer (livré dans WH) est comparable en précision et contrôlable.
Efficacité gros volumes
Wood2017blacksmoke · Wood2020opti — Stat. Comput., « Faster model matrix crossproducts »		 Efficacité = stockage compact + Cholesky bande de \(W+P_\lambda\) (dpbtrf), algèbre bande classique (Golub & Van Loan). L'efficacité gros volumes de mgcv vient de la discrétisation des covariables et du calcul accéléré de \(X^TWX\) (discrete.c, row-Kronecker, QR par blocs, Cholesky de \(X^TWX\)). Largement sans objet pour WH : \(X=I\) ⟹ pas de \(X^TWX\) à former ni à accélérer. Le levier de WH est la bande de \(P_\lambda\), pas la discrétisation — mécanismes distincts, pas un retard.
Réduction de rang / bases
papier : Currie2006 (GLAM), Demmler-Reinsch · mgcv : Wood2004		 Non implémentée. Le papier décrit la paramétrisation naturelle (Demmler-Reinsch) + réduction de rang via GLAM (Currie2006) pour accélérer le 2D ; le code reste en base pleine (les valeurs propres ne servent qu'au log-déterminant). mgcv repose de base sur des bases de lissage à rang réduit (thin-plate regression splines, Wood2004) — la troncature de rang est la primitive de tous les smooths. WH reste exact (base pleine) + bande. La réduction de rang (gain majeur en 2D volumineux) vit dans le package frère WHfull. Voir §5-B.

Bilan : aucun de ces écarts n'est une erreur. Ce sont (i) des méthodes du papier qui vivent dans le package frère WHfull (Fellner-Schall, Newton, nesting alternatif, réduction de rang), pas dans le WH léger de CRAN ; et (ii) une frontière de périmètre nette — le gros-volume « à la Wood » suppose \(X\neq I\), hors du terrain de WH. Détail et partition en §5.

5 · Corrections / améliorations proposées

La confrontation code↔papier↔Wood est close et n'a révélé aucune divergence dure. Ce qui reste tient en trois points, désormais tranchés : deux relèvent d'un choix de partition assumé entre deux packages (A, B), le troisième d'une heuristique d'implémentation documentée ci-dessous (C).

Deux packages, une partition assumée : WH ↔ WHfull
Le package WH publié sur CRAN est volontairement le sous-ensemble léger du papier : sélection de \(\lambda\) par itération externe (outer) avec un optimiseur sans dérivée (Brent / Nelder-Mead), et algèbre bande seule. C'est exact, robuste, et suffisant pour l'usage actuariel courant. Les méthodes plus riches du papier — Fellner-Schall, Newton, nestings performance / alternate, réduction de rang / GLAM — vivent dans un package frère, WHfull (version complète de WH ; github.com/GuillaumeBiessy/WHfull, documentation propre). Les items A et B ci-dessous ne sont donc pas des manques de WH mais cette frontière de périmètre, assumée et délibérée.

A · Un seul optimiseur (sans-dérivée) dans WH — par choix CHOIX ASSUMÉ

Constat. Le papier développe 8 combinaisons (3 nestings × algorithmes) et les compare ; WH ne livre que outer iteration + sans-dérivée (Brent/Nelder-Mead). Fellner-Schall, Newton, performance et alternate iteration n'y sont pas.

Code dit. WH_outer appelle optimize/optim. Papier dit. Newton (dérivées de la LAML, Wood2011) est le plus rapide+précis ; Fellner-Schall (Wood2017fellnerschall) suit ; le sans-dérivée reste <10⁻⁷ d'erreur LAML et « suffisant » (les pas PIRLS sont triviaux car \(X=I\)).

Décision
Ce n'est pas un manque. WH (CRAN) reste délibérément l'optimiseur unique, sans-dérivée — simple, robuste, et démontré suffisant (<10⁻⁷ d'erreur LAML). Les autres optimiseurs et nestings (Fellner-Schall, Newton, performance / alternate) sont fournis par le package frère WHfull (cf. encart ci-dessus). Aucune action sur WH.

B · Réduction de rang / GLAM : absente de WH, portée par WHfull CHOIX ASSUMÉ

Constat. Le papier consacre une section (§sec-vp, §sec-rr) à la paramétrisation naturelle (Demmler-Reinsch) et à la réduction de rang (accélération majeure en 2D via GLAM, Currie2006 — technique de Currie, pas de Wood). WH utilise uniquement l'optimisation bande (algèbre bande classique, exacte) ; les valeurs propres calculées ne servent qu'au log-déterminant.

Décision
La variante « bande » de WH est exacte et suffisante aux tailles actuarielles usuelles : on la conserve telle quelle sur CRAN. La réduction de rang / GLAM (gain en 2D volumineux) est portée par le package frère WHfull. Aucune action sur WH.

C · Une heuristique d'initialisation non décrite : lambda_start_ratio DOC

Constat. Des deux « heuristiques » suspectées en v0, une seule l'est réellement :

  • auto_transpose — fausse alerte : c'est dans le papier. La condition du code (transposer si \((q_x{+}1)/n_x<(q_z{+}1)/n_z\)) est algébriquement identique à la règle de permutation de §sec-reduction (« dimensions \(x\) et \(z\) permutées pour une efficacité maximale »). Rien à faire.
  • find_starting_lambda (R/tools.R) — réellement non décrite dans le papier (Appendice, Algorithme 2 : « une valeur initiale arbitraire »).

Sémantique de l'argument — documentée ici. En 2D, find_starting_lambda (R/tools.R) cale le \(\lambda\) initial par uniroot de sorte que la moyenne de \(w/(w+\lambda\,\mathrm{diag}P)\) — une edf/point approchée — vaille lambda_start_ratio (défaut 0,2, soit un point de départ modérément lissé). lambda_start_ratio est un argument formel de WH_outer ; il est atteignable depuis WH(...) via ..., mais absent du roxygen de WH(). Le choix 0,2 est sain et sans incidence sur le résultat final (point de départ de l'optimisation seulement).

Statut
La sémantique est désormais consignée ici, dans ce document de travail. Son ajout au roxygen / au man/ de WH() (exposition officielle de lambda_start_ratio) modifierait le source livrable : il est réservé à un futur cycle dev délibéré (bump de version + resoumission CRAN) et n'est pas fait ici, pour ne pas toucher la version CRAN courante.

Les écarts de méthode (A, B) sont un choix de partition assumé — WH (CRAN : léger, robuste, suffisant pour l'usage actuariel courant) et le package frère WHfull (complet : Fellner-Schall, Newton, nestings perf/alternate, réduction de rang/GLAM).
